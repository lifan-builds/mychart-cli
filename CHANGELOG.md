# Changelog

## 0.1.0

First public beta of the scoped npm package.

- Installable `mychart-cli` executable for Node.js 20 or newer.
- Stable per-user data directory with legacy checkout compatibility.
- Offline synthetic demo.
- Private local file permissions for records and exports.
- Redacted machine-readable summaries and browser status output.
- GitHub CI, release packaging checks, and PHI-safe support templates.
